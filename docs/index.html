文字會被上傳嗎？
掃描不會，在你的瀏覽器裡跑。按「改寫」才會把那篇文字送到我們的伺服器交給 AI 模型改，免費版改完不留檔。
它會幫我改字嗎？
會。掃完按「改寫」，左邊原文、右邊改好的，一段對一段。改寫版你自己看過再用。
免費版能改幾次？
每月 5 篇，字數不限。付費版不限次數。
上傳的 Word、PDF 會被存起來嗎？
不會。檔案在你的瀏覽器裡拆開，只有文字段落送去改寫；改好的檔案也是在瀏覽器裡組回去的，整份檔案不會離開你的電腦。
命中了一定要改？
實線是該改，虛線標「待確認」，你自己判斷。
可以貼 HTML 嗎？
可以，會先去標籤再掃。
誤判怎麼辦？
寫信來，附上那句話。規則會改。
怎麼取消訂閱？
帳號頁按取消，用到期末為止。
