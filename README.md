# 去 AI 味檢查

貼上文字就掃出 AI 腔用詞的小工具。單一 HTML 檔、純前端、離線可用，不上傳、不呼叫 API、不改字——只告訴你哪裡犯規、屬於哪一類、該怎麼改。改字還是人來。

## 用法

兩種都可以：

- **直接開**：下載後雙擊 `index.html`
- **起伺服器**：雙擊 `開啟去ai味小工具.bat`（需要 Node.js），會在 <http://localhost:8731> 起一個本機伺服器並自動開瀏覽器；同一個 wifi 下的手機也連得上

貼純文字或 HTML 都可以。貼 HTML 會先去掉標籤再掃，不會被 inline style 誤判。

## 檢查什麼

43 條正則，分六類：

| 類別 | 抓什麼 | 例子 |
| --- | --- | --- |
| A 灌水開頭 | 教科書過渡詞、宣告式開場、換段報幕 | 深入探討、先誠實講、X 講完了來接 Y |
| B 浮誇強調 | 把小事講得驚天動地 | 至關重要、觸目驚心 |
| C 情緒假詞 | 裝熟、空洞的社群腔 | 懂的都懂、接住你的情緒 |
| D 經典 AI 句型 | 抓包率最高的那幾種句式 | 這不是⋯而是⋯、破折號、出手 |
| E 空洞／格式殘留 | 空洞讚美、模糊歸因、Markdown 沒清乾淨 | 有人認為、`**` |
| F 抽象化 | 概念名詞化、缺乏具體錨點 | 效率的提升、某個午後、大幅提升 |

命中處在全文區畫底線，滑鼠移上去看改法；右邊清單依類別分組、每筆標了類別代號，點一筆會跳到位置。

**朱紅底線是命中，墨色虛線是待確認。** 破折號 `——`、`從⋯到⋯`、`非常／相當／極為` 這三條不一定要改，所以另外計數，免得每篇都被破折號洗版、數字失去意義。

正則抓不到的部分放在頁面最下方當人工檢查：能不能拍成電影？唸出聲會不會像作文範本？看得到「誰」嗎？

## 規則來源

整理自維基百科《人工智慧寫作跡象》、經理人〈抓包 AI 味指南〉、數位時代〈AI 味具體是什麼〉三篇，加上實際寫稿踩到的案例。規則本體在 `index.html` 的 `<script>` 最上方，用註解標成獨立區塊，要加減規則直接改那一段。

規則格式是 `[正則, 類別, 說明, 選項]`：

```js
[/深入(探討|挖掘|了解)/g, "A 灌水開頭", "AI 灌水開頭，直接講下一件事"],
[/——/g, "D AI句型", "破折號濫用，99% 秒判 AI", {soft:true}],
```

選項 `soft: true` 是「待確認」；`scope: "heading"` 只掃像標題的行（單獨成行、30 字內、結尾沒標點，或 `#` 開頭）；`scope: "raw"` 掃原始輸入而非去標籤後的文字。

## 插圖

版面是漫畫分格風，五個圖框吃 `assets/` 底下的檔案：`hero.png`（橫幅 3:1）、`strip.png`（插頁 3:1）、`side.png`（4:3）、`mark.png`（方形印章）、`portrait.png`（直式）。檔案不在就顯示網點底的提示框，功能不受影響。
